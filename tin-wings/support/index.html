Help with flying, solo battles, survival, and private online rooms.

How do I fly?

Use the left throttle to control power and your device controls to turn. Fire the gun for sustained attacks, launch limited rockets for heavier damage, and use Eject when your plane is in danger.

What happens after ejection?

Deploy your chute, drift toward safe ground, and reach the barn to return in a fresh plane.

Joining an online room

Enter the four-character code supplied by the host. If a code is invalid or the room has ended, Tin Wings keeps you on the Join Code screen so you can correct it or go back.

Troubleshooting online play

  • Confirm every player has an active internet connection.
  • Check that the room code was entered exactly as shown.
  • If the room no longer exists, ask the host to create a new one.

Contact support

Include your device model, operating-system version, game mode, and a short description of what happened. A screenshot is helpful when something looks wrong.
