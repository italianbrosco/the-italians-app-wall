Rooted support

Rooted In God's Word is in internal testing. The currently available build is 1.0.0 (2), with a temporary interface and local guest study. A public download link is not available on this page.

Start studying

Start a guest profile. Open Library, choose My content packs, and import a private pack. The importer accepts an authored Rooted study-pack JSON file smaller than 50 MB. Ordinary Bible JSON files, PDFs and audio files require conversion first. Use material you are entitled to use.

The current build does not include a public Scripture library. An empty library is expected before importing a compatible pack. Importing does not change your chosen translation.

Practice and check an answer

Choose a short set. Type, recall silently or aloud, or ask a nearby listener to check. Finish recalling before revealing the supplied comparison. Words, meaning and references use different checks. For meaning, compare every supplied essential and qualification. Effort reports do not determine correctness.

Visible help stays marked as assistance. Success during practice is different from a later recall check. Progress reports the checks you completed; it does not measure spiritual maturity.

Pause and return

Use Save and leave from the stop options. Resume through Learn and Saved activities. Completed checks stay saved. Resuming an interrupted response does not make it an uninterrupted recital.

Import, save or audio problems

Use Choose a local file and keep your original file. An import error should leave existing study data intact. If saving fails, keep the app open if possible, read the recovery message, and use Retry or export the pending work. Free device storage if the device reports it is full. Avoid clearing app data while recovering an unsaved change.

Listening uses device speech. Check output volume and installed voices. Recording is optional; typing, self-checking and listener comparison remain alternatives. The app does not recognize or automatically grade speech.

Cloud controls are unavailable

Builds 1 and 2 have no configured Rooted cloud service. It cannot create cloud accounts, post group contributions or deliver in-app support cases. Local guest study remains available. An unavailable or pending action is not a confirmed server action.

Preserve your records

Use readable export to save a copy of accessible records. It may contain private notes and imported material, so choose its destination carefully. Build 2 can preview and merge a compatible backup for the same profile, preserving newer records and a separate pre-restore copy. Build 1 does not restore an exported backup. Device backup behavior is controlled by your operating system.

Report a problem

Use TestFlight feedback or email ciminillo@italianbrosco.com. Include the app build, device and operating-system version, screen name, steps and observed result. A short reproduction using nonprivate text is useful.

Do not send passwords, verification codes, full licensed packs, private recordings or personal notes. Review screenshots before sharing them. Read the privacy notice for details.
